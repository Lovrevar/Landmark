Phase 0 — snimanje rečenica

Serve this folder on localhost (see README) and use Chrome or Edge, so the folder picker can write the WAV files and manifest.csv directly. The script is five files plus assignment.csv, which says which takes this speaker records: the primary half by default, or the other half with ?session=complement. Order is shuffled with the speaker ID as the seed. Reopening the page resumes, skipping takes already in the folder. Recording is blocked until every row is frozen and no entity is a placeholder (add ?dryrun=1 for a test run).
