Phase 0 — spot-check of recorded takes

Serve this folder on localhost, as for the recorder, so the sentence text can be shown next to each take. The sample is random per speaker; the seed is shown so a sample can be drawn again exactly. Keys: Space replay · Enter OK and next · F flag and next · ← back.

·

To re-record flagged takes, delete those files from the takes folder and reopen the recorder for that speaker and session: its resume step asks for exactly the missing takes.
