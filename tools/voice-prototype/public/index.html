nije spojeno

Local LiveKit server, Soniox speech-to-text (EU), ElevenLabs v4 Turbo, and a stub LLM with fixed answers. Use headphones, so the agent doesn't hear itself.

Test
  1. Latency: ask 10 short questions, e.g. "Koliko ugovora ima projekt Tar?". Wait for each answer.
  2. Barge-in: say "daj mi pregled" for a long answer and interrupt it mid-sentence. Repeat 20 times.

The agent logs every reply and interruption; npm run report sums them up.
